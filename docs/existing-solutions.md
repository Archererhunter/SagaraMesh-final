# Existing Solutions and Differentiation

| Existing Solution | What it does | Limitation | How SagaraMesh differs |
|---|---|---|---|
| ISRO DAT-SG | Sends distress alert through satellite for fishermen | Device-based and satellite-dependent | Shared floating mesh infrastructure with rescue assessment |
| EPIRB | Sends emergency beacon via satellite | Expensive for small fishermen | Community buoy network reduces individual cost |
| PLB | Personal emergency locator | Individual safety device only | Supports whole fishing routes/community |
| AIS MOB | Man-overboard alert to nearby vessels | Mainly alerts nearby ships | Relays to shore through floating mesh |
| GMDSS | Global maritime safety communication | More suited for formal/larger vessels | Targets small coastal fishermen |
| Tsunami buoys | Monitor ocean conditions | Sensing-focused, not fisherman communication | Combines communication, warning, rescue, and monitoring |
| Smart buoy research projects | Solar/LoRa/GPS prototypes | Usually limited research concepts | Adds rescue deployment, self-repositioning, and community model |

## Key Differentiation

SagaraMesh is not just an SOS device. It is a renewable-powered floating communication and autonomous rescue layer for the sea.
