# Components

## Boat Device

- SOS button
- GPS module
- LoRa/radio module
- Battery
- Waterproof casing
- Indicator LED or small display
- IMU/accelerometer/gyroscope for unusual tilt detection
- Water level or bilge sensor for flooding detection
- Pressure/depth sensor for sinking risk detection
- Buzzer for local warning
