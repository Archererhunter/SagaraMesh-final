# Feasibility, Scalability, and Affordability

## MVP Feasibility

A basic prototype can be built using:

- ESP32 / Arduino / Raspberry Pi Pico
- LoRa modules
- GPS module
- SOS push button
- Solar panel
- Battery and charge controller
- Waterproof box
- IMU sensor for tilt detection
- Water level sensor for flooding detection
- One floating buoy prototype
- One boat transmitter
- One shore receiver
- Simple web dashboard

## Demo Flow

```text
Press SOS
↓
GPS location captured
↓
LoRa sends data
↓
Receiver gets alert
↓
Dashboard shows emergency
↓
Acknowledgement sent back
↓
Drone/payload deployment simulated
↓
Anchor drift correction simulated
↓
Tilt/flooding automatic SOS simulated
```

## Affordability

SagaraMesh is affordable because the expensive buoy infrastructure is shared by many boats. Fishermen only need a simple low-cost boat device, while government, cooperatives, NGOs, CSR programs, or harbor authorities can fund buoy deployment.
