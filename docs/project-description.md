# Project Description

**SagaraMesh** is a solar and wave-powered autonomous floating sea rescue mesh designed to improve fishermen safety. It uses smart floating buoys placed across fishing routes to relay SOS alerts, GPS locations, weather warnings, and rescue messages between boats and shore command centers when mobile networks fail.

In emergencies, the system can deploy a drone, emergency payload, or underwater robot to assess the situation and report back to rescue teams. The buoys can detect anchor detachment and move back to their preset GPS location, making the system reliable, renewable-powered, scalable, and useful for coastal communities.

## Problem

Many fishermen travel into sea zones where mobile networks are weak or unavailable. During storms, cyclones, boat failure, medical emergencies, communication failure, or navigation issues, they may not be able to contact rescue teams or receive warnings.

## Solution

SagaraMesh creates a shared floating safety network using solar and wave-powered smart buoys. These buoys form a mesh communication layer between boats and shore stations, enabling SOS alerts, GPS tracking, weather warnings, rescue acknowledgement, automatic distress detection, and emergency assessment through drones or underwater robots.
